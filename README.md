# 📈 NSE & BSE Stock Market Analyzer Dashboard

This project is an AI-style stock market analysis dashboard that scans multiple NSE and BSE stocks to identify high-potential investment opportunities.

## 🔍 What This Dashboard Does
- Analyzes multiple stocks from NSE and BSE
- Calculates analyst-style target prices (Low, Mean, High)
- Generates confidence scores and BUY / HOLD / AVOID signals
- Identifies top stocks for short-term and long-term outlook
- Allows side-by-side comparison of multiple stocks
- Optimized for fast bulk analysis

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas, NumPy
- Yahoo Finance (yfinance)

```bash
pip install -r requirements.txt
